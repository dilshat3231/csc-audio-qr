# Costas–Sidon Code (CSC) — звуковой QR-код

Учебный проект: звуковой матричный код, в котором рабочие частоты образуют множество Сидона,
а начало сообщения отмечено массивом Костаса.

**Сайт:** `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

## Что внутри
- `index.html` — сайт (работает целиком в браузере, без серверов и библиотек):
  проверка теорем, кодирование текста в звук (проиграть / скачать WAV),
  декодирование из файла или с микрофона, эксперимент с моделью канала.
- `csc_all.py` — тот же алгоритм на Python (нужен только numpy) с автотестами.

## Параметры
Fs = 44100 Гц, N = 4096 отсчётов на символ (~0,093 с), 11 рабочих частот, 3 тона в символе,
7 бит на символ, преамбула — массив Костаса порядка 10 (построение Уэлча, p = 11), контрольная сумма CRC-8.

## Ограничения
Результаты эксперимента на сайте — компьютерное моделирование, а не измерения на реальных устройствах.
