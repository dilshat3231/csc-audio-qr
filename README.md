# Costas–Sidon Code (CSC) — звуковой QR-код

Учебный проект: звуковой матричный код, в котором рабочие частоты образуют множество Сидона,
а начало сообщения отмечено массивом Костаса.

**Сайт:** `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

## Что внутри
- `index.html` — сайт (работает целиком в браузере, без серверов и библиотек):
  проверка теорем, кодирование текста в звук (проиграть / скачать WAV),
  декодирование из файла или с микрофона, эксперимент с моделью канала.
- `csc_all.py` — тот же алгоритм на Python (нужен только numpy) с автотестами.

## Параметры
Fs = 44100 Гц, N = 4096 отсчётов на символ (~0,093 с), 11 рабочих частот, 3 тона в символе,
7 бит на символ, преамбула — массив Костаса порядка 10 (построение Уэлча, p = 11), контрольная сумма CRC-8.

## Формат сообщения (версия 2)
Один символ звука (7 бит) на букву: ASCII передаётся как есть, кириллица, цифры и знаки — по таблице
из 128 кодов (заглавная буква = код «shift» + строчная).
Кадр: **2 символа заголовка** (1 бит режим ASCII/таблица + 13 бит длина) → текст → **2 символа CRC-14**.
Длина — **до 1000 символов** (в таблице с заглавными буквами это до 2000 кодов звука).
Формат несовместим с версией 1 (1 символ заголовка, CRC-7, до 63 символов): звук разных версий не читается.

Режимы скорости: «Стандарт» (окно 4096 отсчётов, преамбула 10), «Быстро» (2048, преамбула 6, Уэлч p = 7),
«Турбо» (экспериментальный: 1024, преамбула 4; тоны ближе друг к другу, в модели канала ошибается чаще).

### Автоускорение
Если сообщение длиннее порога (по умолчанию 200 символов, настраивается на сайте, 1000 — отключить),
оно звучит в режиме «Турбо». Для 1000 символов это примерно 25–50 с вместо 1,5–3 мин в «Стандарте».
Приёмник **сам подбирает режим**: пробует все три и принимает тот, где сошлась контрольная сумма.

### Выбор секунды
- «Начать код с секунды» — тишина перед сообщением (до 60 с), чтобы успеть включить запись.
- «Анализировать с секунды записи» — с какого места записи приёмник ищет преамбулу (окно поиска 40 с).
  Поиск начала считает каждый кадр один раз, поэтому длинные записи обрабатываются за секунды.
- Длительность записи с микрофона задаётся (3–300 с).

## Ограничения
Результаты эксперимента на сайте — компьютерное моделирование, а не измерения на реальных устройствах.
